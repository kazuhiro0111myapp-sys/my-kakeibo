マイ家計簿 iPhone PWA 試作版

【機能】
・月次収入／支出／収支
・三井住友銀行、ソニー銀行、PayPayのCSV取得手順案内
・CSVファイル選択、取り込み前プレビュー、毎回の明示承認
・同一取引の簡易重複検出
・残高の手動記録
・取引の手入力
・JSONバックアップ書き出し
・IndexedDBによる端末内保存（外部クラウドなし）

【iPhoneで使うには】
PWAとしてホーム画面に追加するには、HTTPSで公開する必要があります。
1. このフォルダのファイルをHTTPS対応の静的ホスティングに配置
2. iPhoneのSafariで公開URLを開く
3. 共有ボタン →「ホーム画面に追加」

【制約・注意】
・銀行アプリやPayPayアプリの画面を自動操作しません。外部サービスへログイン情報を送信しません。
・各サービスのCSV仕様は変更されることがあります。現段階のCSV解析は一般的な日本語列名を推定する試作で、実ファイルでの検証が必要です。
・三井住友銀行／ソニー銀行／PayPayの各画面・CSVの最新手順は、アプリやWebサイトの更新で変わる可能性があります。
・残高はCSVから確実に取得できるとは限らないため、現在は手入力です。
・IndexedDBは端末内ブラウザ保存です。SafariのWebサイトデータ消去や端末故障で消える可能性があります。定期的にバックアップを保存してください。
・本番の金融データを登録する前に、サンプルCSVで十分に動作確認してください。
